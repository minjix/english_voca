# 저장소 연결 작업 계획

## 상황
- 로컬 디렉토리(D:\Workspace\english_voca)는 빈 폴더이며 git 저장소 아님
- 원격 저장소(https://github.com/minjix/english_voca.git)는 존재하지만 커밋 없는 빈 저장소

## 작업 내용
- [x] `git init`으로 로컬 저장소 초기화
- [x] `git remote add origin https://github.com/minjix/english_voca.git` 로 원격 연결
- [x] 기본 브랜치를 `main`으로 설정
- [x] 연결 확인 (`git remote -v`)

## 참고
- 원격/로컬 모두 비어 있어 별도 커밋이나 push는 진행하지 않음 (필요 시 추후 요청)
